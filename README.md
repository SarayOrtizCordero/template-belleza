# Lumina Serenity — Centro de Bienestar de Lujo

Plantilla web de una página para un centro de estética y bienestar de lujo en Madrid. Desarrollada como sitio a medida para cliente freelance: sitio de marketing completo, sin frameworks ni build step.

**[Ver demo en vivo](https://sarayortizcordero.github.io/template-belleza/)**

## Secciones

- **Hero** — presentación y llamada a la acción a reservar
- **Servicios** — tratamientos faciales, masajes holísticos, circuitos de agua, aromaterapia
- **Filosofía** — mensaje de marca
- **Galería** — instalaciones del centro
- **Testimonios** — opiniones de clientas
- **Reservar** — formulario de reserva con validación y estado de confirmación
- **Contacto** — WhatsApp, teléfono y ubicación en el footer

## Stack

- **HTML5** — semántico, con `aria-label` en los accesos principales
- **CSS3** — variables personalizadas, Grid y Flexbox, diseño responsive
- **JavaScript** — vanilla, sin dependencias

## Estructura

```
├── index.html
├── css/styles.css
├── js/script.js
└── assets/images/
```

## Cómo verlo en local

Abre `index.html` directamente en el navegador o sírvelo con cualquier servidor estático:

```bash
npx serve .
```
